# Support

For help with a Kanagawa theme, first check the README and issue tracker of the
repository for that application.

## Port-specific issues

Report installation problems, visual bugs, and feature requests in the relevant
port's issue tracker. Include the application and theme versions, operating
system when relevant, steps to reproduce the problem, and what you expected to
happen. Do not post passwords, access tokens, or other secrets.

If the problem is in the application itself or in an upstream project the port
uses, report it to that project when appropriate. Keep Kanagawa port issues in
the port repository.

## Shared organization issues

Use this repository's issue tracker for questions about shared organization
resources, the README template, shared branding, or proposals for a new port.
